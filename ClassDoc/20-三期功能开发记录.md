## 2. 接口清单（`/api/v1`）

### ASR

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/sidebar/asr/transcribe` | Fake/占位 ASR；可写语音消息 + `asr_text`；失败返回错误文案，不阻断文本建议 |

### 回复（扩展）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/sidebar/reply/suggest` | `scene=cs` 或 `service`→`cs`；复用 feedback |
| GET | `/sidebar/reply/latest` | 返回可含 `based_on_asr` |

### 日程

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/sidebar/schedules/suggest` | AI 待办草稿（suggestion type=schedule）；SSE `schedule_draft` |
| GET | `/sidebar/schedules` | `items` 已确认 + `drafts` 草稿 |
| POST | `/sidebar/schedules/confirm` | 落库；`sync_calendar=true` 时企微日历未接入 → `sync_state=failed` 仍保留站内 |
| POST | `/sidebar/schedules` | 手工创建 |
| PATCH | `/sidebar/schedules/{id}` | 更新 |
| GET/PATCH | `/sidebar/schedules/pref` | `remind_pref` |
| POST | `/sidebar/schedules/{id}/remind` | `weak`→SSE `weak_tip`；`strong` 可降级不崩溃 |

## 3. 分层与文件（设计模式）

```
表现层     apps/sidebar  SchedulePanel / WeakTipBar / App
           backend/.../asr/router.py  schedule/router.py
应用层     schedule/pipeline.py  reply/pipeline  remind.py
领域/契约  schedule/schemas.py  serializers.py
基础设施   ai/gateway.py  providers/{fake,asr_fake,deepseek}  calendar.py
```

| 路径 | 说明 |
|------|------|
| `backend/migrations/versions/0003_schedule_item.py` | 迁移 |
| `backend/app/core/models.py` | `ScheduleItem` |
| `backend/app/features/asr/router.py` | ASR API |
| `backend/app/features/ai/providers/asr_fake.py` | Fake ASR |
| `backend/app/features/schedule/{router,pipeline,calendar,schemas,serializers,remind}.py` | 日程 |
| `backend/app/features/ai/providers/fake.py` | cs / schedule 任务 |
| `apps/sidebar/src/composables/{useApi,useSse}.ts` | Facade / Observer |
| `apps/sidebar/src/components/{SchedulePanel,WeakTipBar}.vue` | 日程 Tab / 弱提示 |
| `apps/sidebar/src/App.vue` | 编排：客服场景 + ASR + Tab |

| `ClassDoc/21-三期测试报告.md` | 测试报告 |
