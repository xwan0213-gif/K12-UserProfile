## 3. 错误与处理

| # | 时间 | 步骤 | 错误现象 | 原因分析 | 处理 | 结果 |
|---|------|------|----------|----------|------|------|
| E1 | 2026-08-10 | 初始化前端 | 首次 `npm create vite` 时 `apps/` 不存在，命令无有效产出 | 父目录未先创建 | `New-Item` 创建 `apps/` 后重跑 | OK |
| E2 | 2026-08-10 | `docker compose up` | `failed to connect to the docker API ... dockerDesktopLinuxEngine` | Docker Desktop / `com.docker.service` 未启动 | 启动 Docker Desktop，等待 daemon ready | OK |
| E3 | 2026-08-10 | 构建 api 镜像 | 拉取 `python:3.12-slim` token 连接被对端关闭 | Docker Hub 瞬时网络故障 | 先起 postgres；单独 `docker pull python:3.12-slim` 成功后重建 | OK |
| E4 | 2026-08-10 | 门禁验证（PowerShell） | login/exchange 返回 `JSON decode error` | PowerShell 把 `curl -d "{\"a\":1}"` 转义弄坏 | 改用 `--data-binary "@file.json"` | OK |
| E5 | 2026-08-10 | `POST /mock/seed/demo` | `Internal Server Error`；日志：`can't subtract offset-naive and offset-aware datetimes` | 写入 `datetime.now(timezone.utc)`（aware）到 `TIMESTAMP WITHOUT TIME ZONE` | 种子/登录时间改为 naive UTC（`replace(tzinfo=None)`）；重建 api | OK |
| E6 | 2026-08-10 | api 重建后立刻验证 | curl exit 52 / 空响应 | 容器刚启动，uvicorn 尚未 listen | 轮询 `/health` 就绪后再验 | OK |

## 6. 常用命令备忘

```bash
# 前端构建（Nginx 挂载 dist）
cd apps/sidebar && npm install && npm run build
cd ../admin && npm install && npm run build

# 起停
cd deploy
docker compose up --build -d
docker compose logs -f api
docker compose down

# 种子
curl -X POST http://localhost:8000/api/v1/mock/seed/demo
```

本地后端（可选，需本机可连 Postgres）：

```bash
python -m venv .venv
.\.venv\Scripts\pip install -r backend\requirements.txt
cd backend
..\ .venv\Scripts\alembic upgrade head
..\ .venv\Scripts\uvicorn app.main:app --reload --port 8000
```
