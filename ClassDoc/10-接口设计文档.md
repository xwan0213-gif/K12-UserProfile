## 1. 通用约定

### 1.1 统一响应（非 SSE）

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

| code | 含义 |
|------|------|
| 0 | 成功 |
| 40001 | 参数错误 |
| 40101 | 未登录 / ticket 无效 |
| 40301 | 无业务权限（数据范围外） |
| 40401 | 资源不存在 |
| 40901 | 状态冲突（如草稿已废弃） |
| 50001 | 服务内部错误 |
| 50002 | AI 任务失败（可展示友好文案） |
> code对齐

### 1.2 鉴权

| 端 | 方式 | Header |
|----|------|--------|
| 企微侧边栏 | `POST /auth/wecom/exchange` 换 `access_token` | `Authorization: Bearer <token>` |
| 管理后台 | `POST /auth/admin/login` 换 JWT | 同上 |
| Mock 模式 | `MOCK_WECOM=true` 时可用调试 token | `Authorization: Bearer mock-<user_id>` |

> 常规登录实现即可；**不做**安全专项（刷新轮转、审计网关等）承诺。

### 1.3 数据范围（Scope）

服务端根据 `app_user.role` 自动过滤：

| 角色 | 可见客户 |
|------|----------|
| admin | 全部 |
| regional | 本 org 及子组织 |
| advisor | `owner_user_id = 本人` |

越权访问返回 `40301`。

### 1.4 分页

列表类：

```json
{
  "items": [],
  "page": 1,
  "page_size": 20,
  "total": 100
}
```

Query：`page`（默认 1）、`page_size`（默认 20，最大 100）。

### 1.5 分期标记

接口标注 **MVP / P2 / P3**；未到期接口可返回 `404` 或功能开关关闭。

### 1.6 禁止能力

**不提供**任何「代发企微消息」接口。话术仅返回文本，由前端复制，顾问在企微内手动发送。

### 3.4 修改草稿字段 — MVP

`PATCH /sidebar/profile/draft`

```json
{
  "draft_id": 55,
  "field": "study_info",
  "value": {
    "weak_subjects": ["数学"],
    "score_hint": "期中约70",
    "goal": "考后尽快补差"
  }
}
```

- `field` 枚举：`basic_info` | `study_info` | `prefer_info` | `timeline`
- 允许修改状态为 `draft` 或 `partial_confirmed` 的草稿
- 修改后该字段 `field_status` 置为 `draft`（需再次确认）
- 写 `event_log` 可选

### 3.5 确认画像 — MVP

`POST /sidebar/profile/confirm`

**单字段**：

```json
{
  "draft_id": 55,
  "mode": "fields",
  "fields": ["basic_info", "study_info"]
}
```

**全部**：

```json
{
  "draft_id": 55,
  "mode": "all"
}
```

**忽略草稿**（`mode: discard`）：

```json
{
  "draft_id": 55,
  "mode": "discard"
}
```

**Response data**（示例，全量确认后）：

```json
{
  "profile_version": 3,
  "draft_status": "merged"
}
```

行为：

- `mode=fields` / `all`：将对应 jsonb 分区 **立即 upsert** 到 `customer_profile`（确认本区即生效，不必等全部确认）
- 更新 `field_status`；四区都确认或 `mode=all` 时 draft → `merged`，否则 → `partial_confirmed`
- `mode=discard`：仅将 `profile_draft.status` 置为 `discarded`，**不回滚** `customer_profile`
  - 部分确认后再 discard：已 upsert 的分区保留；未确认内容随草稿作废
- `event_log`: `profile_confirm_field` / `profile_confirm_all` / `profile_discard_draft`

### 3.6 SSE 订阅 — MVP

`GET /sidebar/sse?customer_id=101`

Headers：`Authorization: Bearer ...`；`Accept: text/event-stream`

**事件类型**：

| event | data 示例 | 阶段 |
|-------|-----------|------|
| ping | `{"ts":...}` | MVP 心跳 |
| profile_draft | `{"customer_id":101,"draft_id":55,"confidence":0.82,"job_id":9001}` | MVP |
| job_failed | `{"job_id":9001,"task_type":"profile","message":"分析暂不可用"}` | MVP |
| reply_ready | `{"customer_id":101,"suggestion_id":9}` | P2 |
| tag_recommend | `{"customer_id":101,"suggestion_id":12}` | P2 |
| weak_tip | `{"text":"明日 10:00 试听回访"}` | P3 |
| schedule_draft | `{"suggestion_id":20}` | P3 |

说明：

- 单向推送；断线由前端重连（尽力，非 SLA）
- Nginx 需关闭 proxy buffering
- 同一用户对同一 customer 建议单连接

### 3.10 话术反馈埋点 — P2

`POST /sidebar/reply/feedback`

```json
{
  "suggestion_id": 9,
  "action": "copy",
  "edited_text": null
}
```

| action | 说明 |
|--------|------|
| copy | 复制到剪贴板（**不代发**）；建议仍可继续反馈 |
| adopt | 标记有用（埋点）；非发送；之后 `latest` 不再返回该条 |
| reject | 不适用；之后 `latest` 不再返回该条 |
| edit_adopt | 编辑后标记有用；需 `edited_content` 或 `edited_text` |

侧栏 UX（ClassDoc/31）：主 CTA 为「复制到企微」；「标记有用 / 不适用」仅为反馈；编辑须走真实 `edit_adopt`，禁止传原文冒充。

## 6. 内部 Model Gateway（进程内，非对外 HTTP）

供 Pipeline 调用，**不暴露**给前端（若需调试可加 admin-only 开关）。

**默认供应商（已定）**：DeepSeek（OpenAI 兼容协议）

| 配置项 | 说明 |
|--------|------|
| `LLM_PROVIDER` | 默认 `deepseek` |
| `LLM_BASE_URL` | 默认 `https://api.deepseek.com` |
| `DEEPSEEK_API_KEY` | API 密钥（从环境变量读取，勿写入代码库） |
| `LLM_MODEL` | 默认 `deepseek-chat` |
| `MOCK_LLM` | `true` 时走 FakeLLM，可不配 Key |

```text
generate(task: Literal["profile","reply","tag","schedule"], payload: dict) -> dict
transcribe(audio_ref: str) -> str   # P3
```

实现：`providers/deepseek.py` → `POST {LLM_BASE_URL}/v1/chat/completions`，Header `Authorization: Bearer $DEEPSEEK_API_KEY`。

**profile 返回必须可被 JSON Schema 校验**，示例：

```json
{
  "basic_info": {},
  "study_info": {},
  "prefer_info": {},
  "timeline": [],
  "confidence": 0.82,
  "sources": [{ "type": "chat", "label": "近14日聊天" }]
}
```

解析失败：重试 1 次；仍失败则 `ai_job.failed`，不写脏草稿或写空可编辑草稿（实现二选一，推荐不写脏数据）。
