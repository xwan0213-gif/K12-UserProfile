## 3. 顾问可读交互

| 按钮 | 实际发生 |
|------|----------|
| 手工新建待办 | 立即写入已确认站内待办 |
| 改 / 保存 | `PATCH` 标题、时间、优先级 |
| 完成 / 取消 | `PATCH status`；列表不再显示（仅查 confirmed） |
| 弱 / 强 | 先说明再调用；结果文案含降级 |
| 草稿确认 | 带当前表单为 `edits` |
| 忽略 | dismiss，不建待办 |
