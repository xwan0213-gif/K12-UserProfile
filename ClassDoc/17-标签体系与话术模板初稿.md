## 1. 交付物

| 文件 | 用途 |
|------|------|
| `data/seed/tag_def.json` | 标签定义 + SOP，对应 `POST /admin/tags` |

---

## 2. 字段约定

### 2.1 标签 `tag_def`

| 字段 | 说明 |
|------|------|
| name | 唯一；顾问侧展示名 |
| description | ≤255 字，列表摘要 |
| is_measurable | 可衡量标签优先 `true`（意向、学段、科目、节点类） |
| sop_text | 跟进 SOP：定义 / 动作 / SLA / 禁忌（侧边栏只读） |
| sort_order | 分组排序：意向 10～120、学段 200+、科目 300+、节点 400+、决策特征 500+、服务 600+、来源 700+ |
| enabled | 默认 true |

### 2.2 话术 `script_template`

| 字段 | 说明 |
|------|------|
| scene | `sales` 售前转化 / `cs` 售后服务 |
| stage | `primary` / `junior` / `senior` / `null`（同学段通用） |
| title | 后台检索用短标题 |
| content | 正文；占位符 `{顾问名}`、`【】` 由顾问替换 |
| enabled | 默认 true |

**原则**（对齐需求纪要）：不代发；先价值后价格；小学少用中考话术；禁止绝对化「包提分」。

## 3. 标签分类一览

### 3.1 生命周期 / 意向（可衡量优先）

| 标签 | 核心 SOP 摘要 |
|------|----------------|
| 刚加微信 | 2h 欢迎；48h 无回复转沉睡 |
| 信息收集中 | 三问补齐画像；3 轮无下一步转犹豫 |
| 高意向 | 48h 内邀约试听/到访 |
| 近期决策 | 24h 锁定试听或签约节点 |
| 已约试听 | 预约确认 + 前一日/当日确认 |
| 已试听待转化 | 课后 2h 回访；72h 内 2 次触达 |
| 试听爽约 | 当日改约；两次以上降频 |
| 成交客户 | 欢迎包；移除销售向标签 |
| 犹豫观望 | 周 1～2 次价值触达 |
| 沉睡线索 | 学期节点唤醒 |
| 流失风险 | 2h 主管介入 |
| 续费窗口 | T-21/14/7 节奏 |
| 转介绍潜力 | 满意后邀推荐 |

### 3.2 学段 / 科目 / 节点

小学、初中、高中；数学/英语/物理/化学/语文/全科薄弱；考试临近、寒暑假班意向。

### 3.3 决策与服务特征

价格敏感、多头比价、决策人明确、需试听驱动、重视师资、重视效果数据、时间冲突多、距离顾虑；投诉敏感、满意度高、请假频繁、学习习惯差。

### 3.4 来源与其它

竞品学员、老学员复购、公校重点关注、夜间活跃、语音沟通偏好、需开票/对公、兄弟姐妹同报、活动线索、自然到访。

> 与现有 Mock 种子重叠的名称（高意向、数学薄弱、初中、刚加微信、近期决策）：导入时应 **更新 SOP**，勿重复创建。

## 5. 录入方式

### 5.1 管理后台手工

1. 登录超管 → 标签体系 → 按 JSON 逐条新建（或先导高频 15 条）  
2. 二期上线话术模板页后，按 `scene`+`stage` 录入  

### 5.2 接口批量（标签，MVP 已可用）

```http
POST /admin/tags
Authorization: Bearer <token>
Content-Type: application/json

{
  "name": "近期决策",
  "description": "明确表示近期要报班/选机构",
  "is_measurable": true,
  "sop_text": "24h 内确认试听时间 → …",
  "enabled": true,
  "sort_order": 40
}
```

已存在同名标签：改用 `PATCH /admin/tags/{id}` 更新 `sop_text` / `description`。

### 5.3 脚本导入

```bash
# 在仓库根目录，API 已启动且已 seed 超管账号时：
python data/seed/import_seed_data.py --base-url http://localhost:18000/api/v1 --user admin --password admin123
```
