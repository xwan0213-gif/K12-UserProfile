## 2. 鉴权跳转

| 角色 | 登录后 |
|------|--------|
| advisor | 侧栏工作台 |
| admin / regional | 管理后台 `/admin/` |

- Token key：`k12_access_token`（兼容迁移旧 `admin_token`）
- **同域（Docker `:8080`）**：顾问/管理岗跳转用相对路径 `/` 与 `/admin/`，共享 localStorage
- **跨端口 Dev（5173↔5174）**：`VITE_*` 指向绝对地址时用 `#token=` 交接
- 侧栏不再默认 `mock_code` 换票；演示模式可选手动 Mock 换票

---

## 3. 模拟会话

- `ChatPanel`：左会话列表 + 右气泡线程（家长白底 / 顾问 fjord）
- 发送后 `refreshed` + `stale` → Tab「可更新」；手动生成后清除

---

## 4. 后台 API 增量

- `GET /admin/users` 增加 `has_account`
- `PATCH /admin/users/{id}` 支持 `wecom_userid`
- `POST /admin/users/{id}/account/reset-password`（admin）
