## 3. 问题清单与处置

### E-01 本地缺依赖导致后端无法导入（环境）

- **现象**：`ModuleNotFoundError: No module named 'asyncpg'`
- **根因**：系统 Python 未安装 `backend/requirements.txt` 中依赖
- **处置**：执行 `pip install -r backend/requirements.txt`
- **状态**：已解决（导入成功）

### E-02 画像草稿部分确认后查询/编辑丢失（后端逻辑）

- **现象**：`POST /confirm` 的 `mode=fields` 会把草稿置为 `partial_confirmed`，但：
  - `GET /sidebar/profile` 只查 `status == "draft"` → 刷新后 `draft: null`
  - `PATCH /draft` 拒绝非 `draft` → 无法改剩余字段
  - 管理端客户列表/详情同样只认 `draft`
- **根因**：状态机允许 `partial_confirmed` 继续确认，读路径未对齐
- **处置**：查询与 PATCH 均接受 `("draft", "partial_confirmed")`
  - [`backend/app/features/profile/router.py`](../backend/app/features/profile/router.py)
  - [`backend/app/features/admin/router.py`](../backend/app/features/admin/router.py)
  - 同步补充 [`ClassDoc/10-接口设计文档.md`](./10-接口设计文档.md) 说明
- **状态**：已修复

### E-03 日程建议轮询无提前结束（侧边栏）

- **现象**：`App.vue` 的 `suggestSchedule` 固定轮询 40 次（约 32s），不因草稿出现而退出；`SchedulePanel.suggest` 自身已有正确 early-break
- **处置**：`SchedulePanel` `defineExpose({ load, suggest })`，`App.vue` 改为调用面板 `suggest()`
- **状态**：已修复

### E-04 SSE 正常结束后静默断线（侧边栏）

- **现象**：`useSse.ts` 仅在网络异常时重连；流 `done` 后直接退出
- **处置**：非 abort 的正常结束也触发 2s 后重连
- **状态**：已修复
