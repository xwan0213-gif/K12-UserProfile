## 1. 前端改动

| 文件 | 说明 |
|------|------|
| `apps/sidebar/src/components/suggest/SuggestPanel.vue` | 主 CTA、编辑区、备选操作、结果卡、依据条 |
| `apps/sidebar/src/components/chat/ChatPanel.vue` | 「生成话术/日程（全会话）」；气泡「复制本句」；语音（模拟） |
| `apps/sidebar/src/App.vue` | `replyOutcome` 结果态；feedback 传真实编辑稿；复制后保留建议 |

### 交互说明（顾问可读）

| 按钮 | 实际发生 |
|------|----------|
| 复制到企微 | 剪贴板 + `feedback:copy`；**不代发** |
| 标记有用 | `feedback:adopt`；出结果卡 |
| 不适用 | `feedback:reject`；出结果卡 |
| 编辑 → 标记有用（编辑稿） | `feedback:edit_adopt` + `edited_content` |
| 备选「设为主建议」 | 仅前端切换展示文案 |
| 生成话术（全会话） | 切建议 Tab + 全量 suggest（非单句焦点） |

## 2. 后端

本阶段 **无 API 变更**。沿用：

- `POST /sidebar/reply/suggest`
- `GET /sidebar/reply/latest`（仅 `pending`/`shown`）
- `POST /sidebar/reply/feedback`（`copy` / `adopt` / `reject` / `edit_adopt`）

采纳/拒绝后 `latest` 为空，由前端 `replyOutcome` 展示结果卡。
