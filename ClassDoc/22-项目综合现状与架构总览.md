## 1. 一句话定位

面向 K12 教培顾问的**企微侧边栏智能辅助 + 管理后台**：从聊天/订单/客服摘要抽取客户画像，提供销售/客服话术建议、标签推荐、日程提醒；**AI 只建议、不代发**；草稿须人工确认后生效。

## 4. 逻辑架构（现状）

```
┌──────────────────────────────────────────────────────────┐
│ 表现层                                                    │
│  sidebar H5（画像/建议/标签/日程）  │  admin Web（中后台）  │
└─────────────────┬───────────────────────────┬────────────┘
                  │ HTTPS + SSE               │ HTTPS
┌─────────────────▼───────────────────────────▼────────────┐
│ FastAPI 单体 · Feature-First · /api/v1                    │
│ auth │ context │ profile │ reply │ tag │ asr │ schedule   │
│ admin │ mock │ sse_hub │ event_log │ scope                │
└───────┬──────────────────┬──────────────────┬────────────┘
        │                  │                  │
   PostgreSQL        Model Gateway      企微 Adapter（多数 Mock/Stub）
                     LLM / ASR
```

**架构风格组合**（对齐 ClassDoc 4 / 8）：

| 风格 | 落地 |
|------|------|
| Minimal Monolith | 单 API 进程 + Compose |
| Feature-First | `backend/app/features/*` |
| Pipeline & Filter | profile / reply / tag / schedule |
| Gateway + Adapter | LLM、ASR、calendar |
| 轻分层 | router → pipeline/service → models；DTO 按模块 schemas |
| 进程内 Observer | SSE Hub（非 MQ） |

## 7. AI 管道一览

统一形态：**装载上下文 → Gateway.generate(task) → 解析校验 → 落草稿/建议 → SSE**。

| Task | 产出 | 确认方式 |
|------|------|----------|
| `profile` | `profile_draft` | 字段/全部确认 → `customer_profile` |
| `reply` | `suggestion(type=reply)` | copy / adopt / reject / edit_adopt |
| `tag_recommend` | `suggestion(type=tag)` | confirm 后写 `customer_tag` |
| `schedule` | `suggestion(type=schedule)` | confirm → `schedule_item` |
| ASR `transcribe` | 文本 + 可选 voice 消息 | 失败不阻断文本建议 |
