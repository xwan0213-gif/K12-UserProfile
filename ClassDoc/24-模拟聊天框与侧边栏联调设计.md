# 模拟聊天框与侧边栏联调设计

**项目**：擎天学智 · K12 用户画像推荐系统  
**文档编号**：ClassDoc/24  
**版本**：V1.0  
**编制日期**：2026-08-12  
**目标**：设计一套**模拟企微会话聊天框**，驱动侧边栏全部已交付能力的演示与联调  
**约束**：**仅设计文档，不开发**；不实现真实企微发信；坚持「AI 不代发」。

**关联**：ClassDoc 6 原型、10 接口、15 多客户 Mock、20 三期、22/23/25。

---

## 1. 为什么需要

| 现状痛点 | 聊天框要解决的事 |
|----------|------------------|
| Mock 是「输入框写一条」 | 还原顾问「边聊边看侧栏」心智 |
| 上下文不可见 | 气泡列表 = 画像/话术/日程的输入证据 |
| 语音/时间意图难演示 | 消息类型区分 text / voice(+asr) / 系统提示 |
| 能力入口分散 | 从消息快捷动作触发 suggest / schedule / asr |

**定位**：开发期与试讲期的 **WeCom Chat Simulator**；生产关 Mock 后可隐藏或只读展示真实同步消息。

## 2. 信息架构

```
┌─────────────────────────────────────────────────────────────────┐
│ TopBar：客户选择 · 场景种子 · 能力状态（Mock/LLM/ASR/日历）        │
├────────────────────────────┬────────────────────────────────────┤
│ 模拟聊天框（主视觉 55～60%） │ 能力侧栏（40～45%）                  │
│ · 消息流（上新下旧或反之）   │ · 客户头区                          │
│ · 输入区（文本/语音模拟）   │ · Tab：画像 | 建议 | 标签 | 日程     │
│ · 快捷：「生成画像」等       │ · 弱提示条（可吸顶）                 │
└────────────────────────────┴────────────────────────────────────┘
```

窄屏（企微侧栏常见 320～400px）：**默认只显示能力侧栏**；提供「会话」抽屉/底部 Sheet 打开聊天框（设计态约定，实现时再定）。

宽屏演示（浏览器 ≥960px）：左右分栏默认开启。

## 3. 聊天框功能规格

### 3.1 消息模型（前端视图）

映射后端 `chat_message`：

| 字段 | UI |
|------|-----|
| `direction=in` | 左侧家长气泡 |
| `direction=out` | 右侧顾问气泡（仅 Mock 写入，**不表示系统代发**） |
| `msg_type=text` | 纯文本 |
| `msg_type=voice` | 语音条 + `asr_text` 折叠「已转写」 |
| `msg_time` | 相对时间 / 分隔条 |
| `is_mock` | 小字「模拟」角标（可选） |

系统行（本地 UI，可不落库）：

- 「已触发画像生成」「日程草稿已送达」「转写失败，可继续文本建议」

### 3.2 输入与操作

| 操作 | 行为 | API |
|------|------|-----|
| 发送文本 | 家长/顾问角色切换后写入 | `POST /mock/messages` |
| 模拟语音 | 调 ASR，成功则落 voice + asr_text | `POST /sidebar/asr/transcribe` |
| 插入时间意图话术 | 一键填入「下周六来试听…」 | 本地模板 → messages |
| 从气泡「用于话术」 | 以该条为焦点生成建议 | `POST /sidebar/reply/suggest` |
| 从气泡「识别日程」 | 触发 schedule suggest | `POST /sidebar/schedules/suggest` |
| 刷新会话 | 重载该客户消息列表 | 需 **补消息列表 API**（见 §5） |

**禁止**：任何「一键发送到企微」按钮或接口调用。

### 3.3 与侧栏 Tab 的联动矩阵

| 聊天动作 | 画像 | 建议 | 标签 | 日程 |
|----------|:----:|:----:|:----:|:----:|
| 新文本消息 | 可手动生成 | 可 suggest | 可 recommend | 含时间词可 suggest |
| 语音转写成功 | 上下文含 asr | 展示「基于转写」 | 同左 | 同左 |
| 转写失败 | 不阻断 | Toast + 仍可文本 suggest | — | — |
| SSE profile_draft | Tab 红点/刷新 | — | — | — |
| SSE reply_ready | — | 切到建议并刷新 | — | — |
| SSE tag_recommend | — | — | 刷新推荐卡 | — |
| SSE schedule_draft | — | — | — | 切到日程 |
| SSE weak_tip | 顶栏弱提示（跨 Tab） | 同左 | 同左 | 同左 |
| 复制话术 | — | feedback copy | — | — |
| 确认日程 | — | — | — | confirm；日历降级文案 |

### 3.4 演示脚本（验收用例草稿）

| 脚本 ID | 步骤 | 期望 |
|---------|------|------|
| DEMO-01 | 选「王女士」→ 聊成绩 → 生成画像 → 确认 | 草稿→已确认 |
| DEMO-02 | 家长发价格敏感句 → 销售建议 → 复制 | 埋点；无代发 |
| DEMO-03 | 切客服场景 → 请假/补课句 → 建议 | 话术偏服务 |

## 5. 后端契约缺口（设计级，待开发时立项）

| 缺口 | 现状 | 建议 |
|------|------|------|
| 按客户拉消息列表 | 无独立 sidebar 列表；仅生成时内部 load | 新增 `GET /sidebar/messages?customer_id=&limit=` 或扩展 context |
| 消息分页 | 无 | limit + before_id 即可 |
| 标记已读/焦点消息 | 无 | 前端本地即可，非必须 |
| 场景种子入口 | `/mock/seed/scenario` 已有 | 聊天框顶栏复用 |

**可暂缓**：消息编辑删除、已读回执、多顾问同会话。

现有可复用：

- `POST /mock/messages`、`/mock/seed/demo`、`/mock/seed/scenario`、`GET /mock/customers`
- ASR / reply / schedule / profile / tags / SSE 全套

## 6. 状态与错误

| 状态 | UI |
|------|-----|
| 发送中 | 输入禁用 + 气泡 pending |
| ASR 中 | 语音条 loading |
| ASR 失败 | 系统行红字；不禁用「生成建议」 |
| SSE 断线 | 顶栏「实时连接断开·重连中」 |
| 日历 failed | 日程卡徽标「仅站内」+ 说明 |
| 强提醒 degraded | Toast「已降级，未推企微」 |

## 7. 与 UI 改版关系

- 聊天框是**信息架构升级**（ClassDoc 25 的布局骨架之一）
- 视觉规范、组件态、侧栏 Tab 样式以 25 为准
- 建议同一迭代：**先定 24 交互 → 再套 25 视觉**，避免两套布局打架
